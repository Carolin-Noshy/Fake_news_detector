Fake News Detector
A machine learning project that classifies news articles as real or fake by analyzing patterns in historical news data — writing style, sentiment, source patterns, and other linguistic features commonly associated with misinformation.
Overview
This project uses Natural Language Processing (NLP) and machine learning techniques to detect potentially fake or misleading news articles. By learning from a labeled dataset of past real and fake news, the model identifies recurring patterns (word choice, sentence structure, tone, etc.) that distinguish credible reporting from misinformation.
Features
Text preprocessing and cleaning (tokenization, stemming/lemmatization)
Feature extraction (TF-IDF / word embeddings)
Classification model to predict real vs. fake news
Model evaluation (accuracy, precision, recall, F1-score)

Source: https://www.kaggle.com/datasets/yuktibishambu/liar-dataset-labeled
